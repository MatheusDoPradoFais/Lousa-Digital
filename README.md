# 🖊️ Lousa Digital

Uma **lousa digital interativa**, desenvolvida com **HTML, CSS e JavaScript**, criada para facilitar a transmissão de conhecimento de forma simples, acessível e intuitiva.

O projeto foi pensado para atender diferentes públicos, como **educadores, professores, cursistas, estudantes e qualquer pessoa que queira apresentar ou compartilhar conhecimento** utilizando uma lousa digital.

## 📚 Sobre o projeto

A Lousa Digital busca transformar o computador em uma ferramenta de apoio à aprendizagem e à apresentação de conteúdos.

A proposta é oferecer uma interface simples, permitindo que o usuário escreva, desenhe e organize suas ideias diretamente na tela, sem a necessidade de uma lousa física.

O projeto também pode ser utilizado em diferentes contextos, como:

* 👨‍🏫 Aulas e atividades educacionais;
* 🎓 Cursos e treinamentos;
* 📖 Estudos individuais;
* 💻 Apresentações;
* 🧠 Explicação de conceitos e ideias;
* 📝 Anotações rápidas;
* 🌐 Transmissão de conhecimento.

## ✨ Funcionalidades

* 🖊️ Desenho e escrita livre;
* 🧹 Apagar conteúdos;
* 🎨 Personalização das ferramentas de desenho;
* 📐 Área de trabalho para criação de conteúdos;
* 🖥️ Interface adaptada para utilização em tela cheia;
* 🖱️ Suporte à interação por mouse;
* ⌨️ Utilização do teclado para comandos e interação;
* 📱 Estrutura preparada para futuras melhorias de responsividade;
* ⚡ Funcionamento diretamente no navegador.

> As funcionalidades podem ser ampliadas conforme o desenvolvimento do projeto.

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

* **HTML5** — estrutura da aplicação;
* **CSS3** — estilização e organização da interface;
* **JavaScript** — funcionalidades e interações da lousa.

Não é necessário utilizar um framework para executar o projeto.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd lousa-digital
```

### 3. Execute o projeto

Abra o arquivo `index.html` em um navegador.

Durante o desenvolvimento, também é possível utilizar uma extensão como **Live Server** no Visual Studio Code.

## 🎯 Objetivo

O principal objetivo do projeto é **facilitar a utilização de uma lousa digital como ferramenta de apoio à aprendizagem e à comunicação**.

A ideia é que qualquer pessoa possa utilizar a aplicação para representar visualmente suas ideias, explicar conteúdos e compartilhar conhecimento de maneira prática.


## 👨‍💻 Desenvolvimento

Este projeto está sendo desenvolvido como uma aplicação web utilizando os fundamentos de **Front-End**, com foco em HTML, CSS e JavaScript.

Além de ser uma ferramenta funcional, o projeto também tem como objetivo servir como experiência prática de desenvolvimento, organização de código e criação de interfaces interativas.
